## Pending matrix and decision

The package UI link was observed and restart completed successfully. A fresh DSM cookie session plus its DSM-generated token reached the package CGI, returned `200` with the DSM-authenticated `sander` identity, and reported package-account UID/GID `241653` / `241653`. On 27 October 2026 at `11:46:13 GMT`, the same route without session material returned `HTTP/2 401`, `Content-Type: application/json; charset=utf-8`, `Cache-Control: no-store`, and `{"error":"authentication required"}`. This establishes route availability, one valid authenticated request, package-account execution, and unauthenticated failure without exposing session material.

The same valid cookie-and-token request carrying forged `X-Forwarded-User: root` still returned authenticated user `sander`; the CGI does not accept that browser-supplied header as identity. After DSM API logout of that same disposable session, the cookie-and-token request returned the controlled `401` response, proving logout invalidation reaches the package authentication check. A request carrying deliberately invalid cookie text also returned the controlled `401`; POST returned the controlled `405` method rejection. The expired-session case in [the P1-002A runbook](p1-002a-runbook.md) remains unperformed. The package lifecycle checks are also incomplete. Until they pass, P1-002 remains **blocked**, P1-003–P1-006 remain blocked, and Phase 2 is not ready.
