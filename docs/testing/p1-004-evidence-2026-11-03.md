# P1-004 evidence — 3 November 2026

Status: **complete — unavailable documented original-file handoff**. This is a source-gated negative result for the existing disposable target scope: DSM `7.4.1-90080 Update 1` on `v1000`, with File Station `1.4.4-2221` as recorded during P1-001 and the package custom-CGI route validated in P1-003. It does not make a claim for other DSM builds, architectures, or future Synology documentation.

## Research method

On 3 November 2026, Context7 was resolved for Synology DSM and queried for a DSM 7 third-party package mechanism that evaluates the authenticated user's effective file ACL and supplies the original file handle or stream. Its only authoritative-looking DSM Knowledge Center result returned no matching documentation.

The primary-source review then covered:

| Source | Relevant documented behavior | P1-004 assessment |
| --- | --- | --- |
| [DSM Developer Guide](https://global.download.synology.com/download/Document/Software/DeveloperGuide/Os/DSM/All/enu/DSM_Developer_Guide_7_enu.pdf) | A package custom CGI can invoke `authenticate.cgi` with its CGI environment to obtain the logged-in username. | Matches P1-003 identity derivation only; no effective-file-authorization or file-handle handoff is documented. |
| [File Station API Guide](https://global.download.synology.com/download/Document/Software/DeveloperGuide/Package/FileStation/All/enu/Synology_File_Station_API_Guide.pdf) | `SYNO.FileStation.Download` returns file content, but all File Station APIs require a `SYNO.API.Auth` session with `session=FileStation`; the documented login operation takes an account and password. | It can stream original content only for a separately authenticated File Station session. It does not document creating that session from custom-CGI identity or forwarding the request cookie. |
| [File Station ACL guidance](https://kb.synology.com/en-eu/DSM/tutorial/How_to_manage_ACL_settings_on_your_NAS) | File Station can configure ACLs and its Permission Inspector can display a selected user's permissions. | Documents administration/inspection, not a package-callable, atomic per-user file-open facility. |

## Candidate decision

| Candidate | Result |
| --- | --- |
| P1-003 custom CGI plus `authenticate.cgi` | Rejected: authenticated username is not a filesystem authorization decision or original-file handle. |
| `SYNO.FileStation.Download` using a package-created File Station session | Rejected: creating the documented session requires user credentials, which the package must not receive or retain. |
| `SYNO.FileStation.Download` by replaying the inbound DSM cookie | Rejected: Synology does not document that topology; it would relay session material and violates the adopted strict gate. |
| Package-account filesystem open, ACL/pathname check, broker, or private copy | Rejected by project invariants; none binds the requesting user's DSM ACL decision to the original opened file. |

No documented candidate meets all three required conditions: P1-003-derived caller identity, DSM-effective authorization at open time, and an original-file handle or stream supplied without credentials or privilege elevation.

## Live-validation status

The P1-001 ACL fixtures were removed during its documented cleanup. Since no documented candidate survived source review, recreating fixtures or performing a File Station API call would not validate an allowed implementation and was intentionally skipped. No package-account share permission, temporary copy, browser companion, root broker, setuid helper, global DSM change, or undocumented cookie relay was added.

## Decision

P1-004 is **unavailable** for the stated target scope. The authorization acceptance checks remain unchecked because no user-authorized original-file operation exists. P1-005 and P1-006 are blocked, and Phase 2 is not ready. A future reconsideration requires a published Synology contract that bridges authenticated package custom CGI to effective-user File Station authorization and a single original-file open/stream; it must then rerun the P1-004 runbook on a disposable target.
