## Current result

The package is confirmed to receive and use the DSM-authenticated identity for direct HTTPS requests, and the explicit package policy is confirmed independently of Unix group membership: both `test1` and `test2` have primary group `users` (GID 100), yet only the embedded allowlist changes the `test2` result.

The `test2` response-body substitution is a validation limitation. It does not expose package data, but it prevents a passing claim for the P1-003 requirement that every controlled error retain package JSON and `Cache-Control: no-store`. Do not work around it with a global nginx/DSM change or by weakening the policy.
