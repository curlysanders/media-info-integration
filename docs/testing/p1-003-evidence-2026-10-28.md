## Current result

The package is confirmed to receive and use the DSM-authenticated identity for direct HTTPS requests, and the explicit package policy is confirmed independently of Unix group membership: both `test1` and `test2` have primary group `users` (GID 100), yet only the embedded allowlist changes the `test2` result.

DSM `7.4.1-90080 Update 1` substitutes its generic error representation for the package's `403` on this managed route and removes `Cache-Control`. The observed replacement contains no package data or caller-specific information. P1-003 therefore treats it as a version-scoped DSM boundary: package-controlled responses must retain JSON and `Cache-Control: no-store`; the generic replacement is acceptable only while it remains free of identity, token, request, file, and other caller-specific data. Do not work around it with a global nginx/DSM change or by weakening the policy.

The same DSM version suppresses the body of the package's `401` after DSM logout but retains `Cache-Control: no-store`; the normal expiry path returns the package JSON body. The logout representation contains no caller-specific information. P1-003 treats this as the same version-scoped DSM boundary. Do not work around it with a global nginx/DSM change or by weakening the policy.

## Completion rationale

The complete direct and reverse-proxy request matrix demonstrated authenticated identity binding, explicit policy allow/deny, token and session rejection, origin checks, bounded input, method checks, and resistance to forwarded-header forgery. Normal HTTP clients cannot carry malformed `Content-Length` values through DSM's HTTP parser to CGI; the code-level boundary was instead exercised by the passing `runtime-probe` tests for missing and invalid lengths.

The live package/log inventory and the static audit found no persistence or log emission of request material. The only response-shape deviations are the documented DSM-generated `403` replacement and logged-out-session `401` body suppression; both were observed free of caller-specific data. All other tested package-controlled responses were JSON with `Cache-Control: no-store`.
